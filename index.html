Python Identifiers, Keywords and Indentation

  • Identifiers: names for variables, functions, etc. (must not start with digits).
  • Keywords: reserved words like if, else, def, class.
  • Case-sensitive language.
  • Indentation defines code blocks (no braces {}).
# Identifier

# Keyword
if score > 90:
    print("Excellent")

print(Score)  # prints 80

def greet():
    print("Hi!")

greet()

Understanding Iterators

  • Objects that implement __iter__() and __next__().
  • Used in loops and comprehensions.
  • Built-in functions like iter() and next().
  • Enables lazy evaluation and memory efficiency.
nums = [10, 20, 30]
it = iter(nums)
print(next(it))   # 10
print(next(it))   # 20

for n in nums:
    print(n)

Generators

  • Defined using yield instead of return.
  • Produce items one at a time.
  • More memory-efficient than lists.
  • Ideal for large data streams.
def count_up(n):
    for i in range(n):
        yield i

gen = count_up(3)
print(next(gen))  # 0
print(next(gen))  # 1

Comprehensions

  • Compact syntax for creating collections.
  • List: [x for x in range(5)].
  • Dict: {x: x**2 for x in range(5)}.
  • Set: {x for x in range(5)}.
lst = [x for x in range(5)]
dct = {x: x**2 for x in range(5)}
st = {x for x in range(5)}

print(lst, dct, st)

Loops in Python

  • For loop: iterate over sequences.
  • While loop: run while condition is true.
  • Nested loops: loop inside another loop.
  • Use break, continue, pass for control.
# For loop
for i in range(3):
    print(i)

# While loop
x = 0
while x < 3:
    print(x)
    x += 1

# Nested loop
for i in range(2):
    for j in range(2):
        print(i, j)

# Control statements
for i in range(5):
    if i == 3:
        break
    elif i == 1:
        continue
    else:
        pass
    print(i)

String Manipulation

  • Basic operations: concatenation, repetition, length.
  • Slicing: s[1:4], s[::-1] for reverse.
  • Methods: upper(), lower(), replace(), split().
  • Strings are immutable.
s = "Python"

print(s[1:4])          # slicing
print(s[::-1])         # reverse

print(s.replace("Py", "My"))
print(s.split("t"))

Lambda Function

  • Anonymous function: lambda x: x + 1.
  • Used for short, throwaway functions.
  • Often used with map(), filter(), reduce().
  • No return keyword—expression is returned.
add = lambda x: x + 1
print(add(5))                 # 6

nums = [1, 2, 3]
squared = list(map(lambda x: x**2, nums))
print(squared)                # [1, 4, 9]

Importing Modules – Math Module

  • Use import math to access math functions.
  • Common functions: sqrt(), pow(), ceil(), floor().
  • Constants: math.pi, math.e.
  • Can import specific functions: from math import sqrt.
import math
print(math.sqrt(16))
print(math.ceil(2.3))
print(math.pi)

from math import floor
print(floor(3.9))
